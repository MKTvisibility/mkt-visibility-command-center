# Setup and data preservation

Connect to the same Supabase project using its URL and publishable key. Keep current database tables, membership and authentication accounts. No data import is required.

For a new empty database, review the ordered SQL files in supabase/migrations. The initial migration deliberately refuses to overwrite existing tables. RLS requires approved workspace membership. Edit placeholder UUIDs in supabase/members.example.sql outside the repository before applying.
